========================================================
  screen-control 屏幕操作预设 —— 安装说明
========================================================

【这是什么】

一个 DSH 的 Agent 预设（preset）。装上之后，新建会话时可以选
「屏幕操作」，让 Agent 直接操作你的真实桌面：截屏、识图定位、
打准星校验、模拟鼠标键盘，每轮结束自动清理截图。

注意：这是「预设」，不是普通的 npm 插件包。这一点决定了安装方式，
请看下面的【常见问题】第 1 条。


【安装前确认】

  1. 系统是 Windows。（插件直接调用 Win32 API，其他系统用不了）
  2. 已经装好 DSH，并且能正常启动。
  3. 不需要单独安装 koffi 和 sharp —— 它们随 DSH 一起装好了，
     插件会自己去找到它们。


【安装方式一：脚本安装（推荐）】

  把压缩包解压到任意目录，然后在那个目录里：

  Windows (PowerShell)：
      右键空白处 →「在终端中打开」，然后输入：

          powershell -ExecutionPolicy Bypass -File .\install.ps1

  脚本会自动把预设复制到正确位置，并检查文件是否齐全。


【安装方式二：手动复制】

  如果不想跑脚本，手动复制也一样。压缩包解压后里面有个 preset 文件夹，
  把它整个复制成下面这个名字的文件夹：

      C:\Users\你的用户名\.dsh\.agent-presets\screen-control

  用命令做就是（在解压出来的目录里执行）：

      xcopy /E /I /Y preset "%USERPROFILE%\.dsh\.agent-presets\screen-control"

  复制完确认这个文件存在：

      %USERPROFILE%\.dsh\.agent-presets\screen-control\agent.cordis.yml


【装完怎么用】

  1. 重启 DSH
  2. 新建会话
  3. 在输入框上方点预设选择器，选「屏幕操作」
  4. 直接用自然语言下指令，例如：

         打开B站
         把这个浏览器窗口关掉
         在这个页面搜索 xxx，打开第一条结果

  Agent 会自己走完：截屏 → 叠网格 → 压缩 → 定位 → 准星校验 → 点击 → **重新全屏截屏确认最终状态** → 清理。


【怎么确认装成功了】

  重启 DSH 后新建会话，预设选择器里能看到「屏幕操作」，
  就说明装好了。

  用命令行检查文件是否到位：

      dir "%USERPROFILE%\.dsh\.agent-presets\screen-control"

  应该看到：agent.cordis.yml、preset.yml、SPEC.md、
  screen-control-plugin 文件夹、screenshots 文件夹。


【截图存在哪】

  所有截图只写这一个目录：

      %USERPROFILE%\.dsh\.agent-presets\screen-control\screenshots\

  命名格式：r轮次_阶段_时间戳.png

  桌面、临时目录、别的地方都不会写。每轮结束会自动删干净。


【卸载】

  直接删掉这个文件夹就行：

      %USERPROFILE%\.dsh\.agent-presets\screen-control

  然后重启 DSH。


========================================================
  常见问题
========================================================

问 1：能不能用 dsh 命令直接安装？

  不能。

  dsh 只有两个子命令：dsh web 和 dsh plugin。
  dsh plugin --profile web add <包> 的实际作用，是把参数转发给
  profile 目录里的 pnpm，也就是把包装进 node_modules。

  而 DSH 找预设时，只扫描下面这两个位置：

      - DSH 自带的 presets 目录
      - %USERPROFILE%\.dsh\.agent-presets\

  它不会去 node_modules 里找。所以用 dsh plugin add 装完，
  预设选择器里不会出现「屏幕操作」。

  这个预设的安装方式就是「把 preset 文件夹复制到 .agent-presets 下」，
  没有别的捷径。


问 2：装完重启了，但预设选择器里没有「屏幕操作」

  按顺序检查：

  1. 路径对不对。必须是
     %USERPROFILE%\.dsh\.agent-presets\screen-control\agent.cordis.yml
     注意 .dsh 前面是点，agent-presets 是复数带横杠。

  2. 有没有真的重启 DSH。不重启不会加载新预设。

  3. 看 DSH 的界面里这个预设是不是显示为「损坏」。如果显示损坏，
     多半是 screen-control-plugin 文件夹没一起复制过去。

  4. 如果你设置了 DSH_HOME 环境变量，路径要跟着变：
     %DSH_HOME%\.agent-presets\screen-control


问 3：点了没反应 / 报权限错误

  如果你的目标是「以管理员身份运行」的程序，Windows 会拦截普通权限
  进程发过去的鼠标键盘消息（这叫 UIPI）。这种情况下插件会明确报错，
  不会假装点成功。

  解决办法：让 DSH 也以管理员身份运行。


问 4：Agent 说点偏了 / 报「NOTHING CHANGED AT THE TARGET」

  这是防护机制在工作，不是故障。说明点下去之后目标位置的画面
  没有变化，可能点空了或者那个控件没响应。

  它不会硬说成功，会如实告诉你。让它重新截屏定位即可。


问 5：屏幕上的字太小，Agent 认不出图标

  它应该会自动放大区域去看。如果没放大就猜，那是它没按规矩来，
  可以在指令里加一句：

         不确定的图标先用放大看清楚再点


问 6：支持多显示器吗？

  代码里支持（副屏在主屏左边时的负坐标有处理），但开发时只有单屏，
  这条路径没有实机验证过。用多屏的话留意一下，有问题请反馈。


问 7：支持什么系统？

  只支持 Windows。插件通过 koffi 直接调用 user32.dll / gdi32.dll /
  shcore.dll，其他系统上挂载会失败。


问 8：为什么点完还要再截一次屏？

  因为「点下去了」不代表「点对了」。点击只能告诉 Agent 指针落在哪儿，
  不能告诉它功能有没有生效。所以每次输入之后，它必须重新做一次
  **全屏截图**看结果，并如实汇报；在那之前，清理工具会拒绝结束本轮。

  放大图（screen_zoom）不算数：它只放大一个矩形区域，看不到屏幕整体，
  只能用来精确定位点击位置，不能用来判断屏幕状态。
